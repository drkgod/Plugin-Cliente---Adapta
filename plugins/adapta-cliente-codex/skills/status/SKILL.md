# Status do projeto

Leia `STATUS.md`, `04_fase-atual/fase.md`, `.adapta-cliente/estado-atual.md` quando existir,
`changelog.md` e `05_entregas/`. Em `fase-format:2`, calcule o progresso por todos os checkboxes,
inclusive subtasks; sem o marcador, use a tabela legada. Informe fase, feitas/total, task ativa,
executor, owner informativo, gate, travas e uma única próxima ação.

Owner ausente ou diferente do executor nunca é trava. Não altere arquivos, não selecione nova task
e não avance gate.
